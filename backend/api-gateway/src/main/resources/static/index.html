SOAP-to-REST JSON Protocol Transpiler

The API Gateway exposes these clean JSON endpoints. When called, the Gateway transpiles the request to SOAP 1.1 envelopes downstream, queries the microservices, and converts XML to JSON.

GET /api/v1/students
Transpiles to getAllStudentsRequest on STUDENT-SERVICE (Neon PostgreSQL).
GET /api/v1/faculty
Transpiles to getAllFacultyRequest on FACULTY-SERVICE (MongoDB Atlas NoSQL).
GET /api/v1/courses
Transpiles to getAllCoursesRequest on COURSE-SERVICE (Supabase PostgreSQL).
GET /api/v1/analytics
Aggregates cross-service data into unified academic intelligence & architecture metrics.

Deploying on Microsoft Azure VM

This system is fully architected for dual-target deployment. To run on an Azure Ubuntu/Windows VM:

  1. SSH into your Azure VM instance.
  2. Clone the repository: git clone https://github.com/mahes359/college-management-system.git
  3. Export your VM's public/private IP: export HOST=<AZURE_VM_IP>
  4. Launch all microservices via Docker Compose: docker compose up -d
  5. Access this Command Center at http://<AZURE_VM_IP>:8080/

Running on Render Cloud

On Render, each microservice operates as an independent Dockerized Web Service with automated HTTPS on port 443. The services dynamically register their *.onrender.com FQDN with Eureka Server, and Gateway routes traffic via lb:// seamlessly.

✓ Eureka Registry: eureka-server-fbb5.onrender.com
✓ API Gateway: api-gateway-wzqo.onrender.com
